Trend_Track

Trend_Track is a Python project for managing and analyzing time-based trend events. The project focuses on object-oriented design, data structures, error handling, and automated testing.

Features
Create and manage trend events
Store events using a 2-3 tree
Search and organize events by date and title
Normalize event titles for consistent searching
Prevent events from being created with invalid dates
Automated testing using Pytest
Comprehensive test suite covering normal and error cases

Testing

TrendTrack uses Pytest for automated testing.

To run the test suite:

pytest

The test suite covers the project's classes, functionality, edge cases, and expected error conditions.
